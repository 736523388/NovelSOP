# 单章生产：准备 → 写作 → 审校 → 定稿 → 状态归档

输入：项目目录、目标章号。输出：可追溯终稿、问题处理记录、已核对的状态变化。所有记录使用 [章节工作包](templates/chapter.md)。

章节状态：`准备中 → 草稿 → 修订中 / 待定稿 → 已定稿 → 已归档`。发布状态另记为 `未发布 / 待审核 / 已发布 / 需处理`，不与创作状态混用。

## 1. 恢复当前任务

读取 `control.md`、当前章工作包、当前账本版本和上一章终稿。检查是否已有草稿、未解决问题、未完成归档。

完成条件：本次要继续的步骤与正文文件明确。已定稿但未归档时先恢复归档；已有草稿则继续处理，不默认从头重写。第一章以经作者确认的初始设定为起点。

## 2. 准备章卡和上下文

读取当前卷目标、待兑现承诺、本章相关人物与物品状态、知情边界、上一章结尾和相关历史原文。保留来源定位。近几章摘要用于定位，关键矛盾回查终稿。

填写本章目标、阻力、选择、代价、具体变化、读者回报、伏笔动作、视角限制、结尾期待。关键转折不明确时比较两种场景方案后选择；常规衔接章直接沿用已确认规划。

完成条件：章卡因果成立；输入可追溯；关键事实缺口已补齐或留给作者裁决。篇幅是目标范围，内容承载不了时调整场景或章卡。

## 3. 形成正文

写作角色依据章卡分场景完成当前草稿，只加载相关材料。以人物行动、对话和必要描写呈现变化，参考作者已定稿样章保持声音。

新增非关键细节可在草稿中尝试；涉及世界规则、核心人物关系、主线方向的改变列入提案。正文外另列新增事实候选、待核实项和偏离章卡之处。

完成条件：正文覆盖章卡主要事件，有可感知变化，并形成完整章节；不是用场景梗概代替正文。保存明确版本，更新工作台。

## 4. 独立审校

审校角色读取该版本正文、章卡、相关设定和证据，分别检查连续性与阅读体验。每条问题必须给出位置、依据或审美理由、影响、最小修法。

| 级别 | 定义 | 下一步 |
|---|---|---|
| A：必须处理 | 与已确认事实或规则矛盾、关键因果不成立、严重信息越界、明显侵权或内容问题 | 修复，或作者明确批准变更并同步受影响内容 |
| B：影响阅读 | 人物动机难理解、主要承诺落空、重复铺陈、声音明显偏移 | 定向修改，或作者说明保留理由 |
| C：可选建议 | 句式、修辞、节奏偏好及可替代写法 | 作者选择采纳与否 |

语义不确定、刻意误导或不可靠叙述列为“待核实”，先定位事实，不直接判为穿帮。输出可以无问题，不设问题数配额。模型自评分只作辅助。

完成条件：审校报告注明所审正文、章卡和账本版本；问题有可操作修法；未验证项明确列出。

## 5. 定向修订与复核

依次处理 A、B，再按需处理 C。结构问题回到章卡，局部问题改对应段落。保存新版本并检查前后段衔接、受影响事实及伏笔。

默认每轮任务最多两轮自动修订；仍有重大冲突时提交具体选择给作者，而不是无限润色。已经批准的调整继续执行，不重复征求同一决定。

完成条件：A 项解决；B 项已修复或有作者明确保留记录；正文变化后相关审校已复核。旧报告保留历史，标明已被新版本替代。

## 6. 作者定稿

提交完整可读稿、重要修改摘要、未决选择和候选状态变化。作者确认具体文件版本后，保存为本章终稿。作者已有明确的日常定稿授权时，按授权范围执行并记录依据；重大方向调整仍按既定边界处理。

完成条件：终稿文件、版本、确认依据和日期已记录。未获定稿的草稿保持候选状态。

## 7. 归档与核对

从终稿重新提取变化，使用 `CH0001-V1` 等唯一归档编号：

1. 记录归档前账本版本，将本次变化放入工作包的候选增量表。
2. 对照正文核对人物、时间、知情、资源、伏笔、读者承诺的变化；仅记录发生了变化的项目。
3. 在单一归档步骤更新 `ledgers.md`，每行注明归档编号与正文位置。更新前保留账本快照。
4. 逐项核对写入数量及内容，更新账本版本和最新归档章号，最后才将章节标为“已归档”。

完成条件：本章事实与终稿一致；候选已逐项处理；工作台记录与账本版本一致。发生中断时，按归档编号核对已有行，补齐遗漏，避免重复增加资源或事件。

## 8. 移交下一步

更新下一章承接点、应检索的历史位置、当前悬线及下一次回报。发布按 [平台节点](03-platform.md) 单独处理。

完成条件：另一上下文只读工作台与相关工作包即可继续，无须依赖本次聊天记忆。

## 改旧章与回退

修改已归档章节时保留旧终稿，创建新版本及变更记录。标记旧审校待复核，列出该事实影响的后续章节与账本行。存在后续依赖时，从最近可靠的账本快照按后续终稿重新核对、重建受影响状态，不能只把当前状态倒退到旧章。

已发布章的修改还需登记平台正文版本；本地修改成功不等于线上已经更新。完成影响检查后再恢复依赖该事实的后续写作。
