## 2. 签约准备

- [ ] 后台显示申请资格，已记录本书申请次数及剩余机会。
- [ ] 书名、简介、开篇兑现同一阅读承诺；人物目标与主线清楚。
- [ ] 当前已发布内容的重大逻辑矛盾、机械重复、无效铺陈已处理。
- [ ] 原创、素材来源与平台内容要求已检查；授权或事实问题已解决。
- [ ] 作者已审阅具体申请材料；合同由作者核阅并处理签署。

结果记录到工作台：提交时间、所用正文范围与版本、平台反馈原文、下一步。失败后先处理具体反馈再申请，保留前后变更。

## 3. 推荐评估准备

- [ ] 已按上表及当前后台复核字数、签约状态、封面、更新记录和剩余次数。
- [ ] 前期卖点已兑现；中段没有重复情节或明显主线漂移。
- [ ] 当前人物动机、时间线、核心资源和重要伏笔已跨章核对。
- [ ] 书名、简介、封面与实际内容一致；封面素材来源可用。
- [ ] 缓冲稿可支持已计划更新；正文质量不依赖机械凑字数。
- [ ] 作者已看到准备报告，申请方式和时机有明确决定。

自动评估计入机会，工作台同步跟踪发布进度。评估失败：归类平台反馈，修复后再决定是否使用下一次机会。内部审校通过只代表材料已准备好。

## 4. 每次发布前

1. 确认书籍、章节号、标题、终稿文件及版本。
2. 检查正文无提示词、审校批注、占位符、重复章、漏段和明显排版问题。
3. 核对实际篇幅、定时安排及当前后台要求；AI 使用情况按实际记录处理。
4. 按作者已有发布授权执行；没有发布授权时交付待发布材料。
5. 登记提交及审核状态，看到平台成功状态后才记录“已发布”。审核拒绝时保留反馈并修订，避免误判为已发布或直接重复提交。

中国现行标识办法要求，用户发布生成合成内容时主动声明并使用平台标识功能。记录资料辅助、结构建议、正文生成、润色的实际使用情况，依番茄当前入口及规则处理；不得以检测器分数替代声明判断。[网信办原文](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

## 5. 卷末及完结前

盘点主要冲突、人物变化、阅读承诺与伏笔；逐条标为已兑现、有意开放或待补。开放结局须有作者意图，遗忘的悬线回到正文修复。检查终章是否完整回应本书的核心阅读承诺。

作者确认结局与线上版本后，再核对完结操作的当前规则及影响；完结标记不能作为试探推荐的临时操作。使用新完本签约路线时，先建立专用规则表再执行，不套用连载申请步骤。
