# 开书：从想法到可持续连载

输入：作者想法、可投入时间、已有稿件；使用 [项目模板](templates/project.md)。目标是选定一本可持续创作的书，并形成经过试写验证的工作方法。

## 1. 明确创作边界

填写项目代号、长篇连载模式、目标读者、题材候选、希望提供的阅读体验、作者熟悉的领域、题材与内容边界、可投入时间。

没有确定题材时进入下一步提出方案；读者与题材尚未选择前，不生成长篇正文。现有稿件先登记版本，确认保留范围。

完成条件：已知内容与待决定事项分开记录，形成不超过五项的关键选择清单。涉及作者偏好的缺口集中询问一次，其他调研继续。

## 2. 市场观察与选题

策划查阅近期同赛道作品及番茄官方资讯。建议目标为 10—15 本可比作品，兼顾新书、稳定连载、完结书，避免只选头部经典。数量不足时如实记录可访问样本与偏差。

记录来源、观察日期、作品阶段、书名简介承诺、实际读到的章节范围、开篇冲突、读者可能期待的回报、可见评论问题。没有读到正文时，只分析书名简介；不编造剧情或后台表现。

输出三个选题方案，每个写清：目标读者、一句话卖点、人物欲望、主要阻力、持续冲突来源、一处有意义的区别、作者需要补足的知识。按作者兴趣、可持续性和样本证据推荐一个，说明代价。

完成条件：作者选定一个方案。市场事实带来源；热度观察与策划推断分开；没有用同义替换复刻单本作品。

## 3. 将阅读承诺落实到开篇

围绕已选题材提出三套书名、简介、开篇切入组合。每套说明标题承诺什么、第一场冲突是什么、前几章如何开始兑现。作者选择方向后，形成项目阅读承诺。

建立足够支撑试写的最小设定：主角目标与缺陷、关键关系、主要对手或障碍、世界规则及代价、叙述视角、作者认可的风格样例。世界资料按情节需要扩充。

完成条件：包装与正文目标一致；人物会采取行动；核心能力或规则有边界；不存在阻断试写的设定矛盾。

## 4. 分层规划

确定全书方向和结局意图、当前卷核心冲突、首个情节段目标。近期细化到章卡，远期保留里程碑。每个情节段说明进入状态、主要选择、阶段性回报、代价和离开状态。

初建账本中的人物、知情边界、事件、资源、伏笔及阅读承诺。未来事件放在计划区，不能提前写入已发生事实。

完成条件：试写章节能形成相连的因果链，后续至少有一个可持续的情节方向；作者认可关键人物与主线走向。

## 5. 连续试写与校准

使用 [章节流程](02-chapter.md) 连续试写 5—10 章，规模可由作者调整。试写暂不触发发布。记录每章修改时间、严重问题、反复失效的指令和实际成本。

作者重点评阅：人物声音是否清晰、冲突是否成立、卖点是否开始兑现、后续是否想写。可以请真实目标读者反馈三个问题：在哪里想停读、哪里想继续读、希望接下来发生什么。没有试读者时标为“未做真实试读”，模型意见归为编辑建议。

完成条件：作者认可一组连续样章及相应风格；主要连续性问题已处理；下一情节段能延续；写作和修订负担符合可投入时间。否则记录具体原因，回到选题、开篇、场景或文风环节处理。

## 6. 进入连载准备

根据试写期间的实际定稿能力设定更新计划，预留修稿和休息时间。建立能覆盖数天更新的缓冲稿目标；起始可按三天尝试，后续依据稳定性调整。这是产能建议，不是平台要求。

读取 [平台节点](03-platform.md)，填写规则核查记录及当前作品状态。作者确认后进入常规章节生产。签约机会和推荐申请依实际发布进度检查，存稿字数不冒充平台发布字数。

完成条件：`control.md` 记录阶段、最新定稿、待发布范围、当前账本版本、下一章任务、未决问题及规则复核日期。
