## 1. 当前有效选择

已选的是本轮讨论的方案一“没有关好的冰箱”，不是O7的C1“餐桌之间”。新版方案二“阳台上的风”、方案三“被挪动的饲养盒”未采用为主链；O7三套供食／控制候选退出当前执行路径。

第一章正式章卡：[chapters/0001/work.md](chapters/0001/work.md)，版本CH0001-C1。章卡中的空间、物件和动作是Agent据授权形成的具体设计，供整体审阅；不逐项要求作者设计。

已定主链：楼顶逃离→阳台进入无人出租屋→觅食恢复→提前察觉住户回来并伏击→主角从冰箱及包装发现异常→尝试退出时遭袭，绞杀未完整形成→短促交锋中识别对方重伤限制→反杀→主角昏迷→本源吞噬遗体及全部相关痕迹→红色物质侵入，初次进化启动。

## 2. 入口、人物与动机

主角住共六层的步梯房顶层。重伤进化者在连片楼顶逃离，确认主角出租屋无人后，从楼顶翻下阳台进入，翻找厨房、冰箱中的食物。没有楼道劫持、胁迫开门、控制主角供食或长期合作。

进化者已有生命感知与吞噬血肉恢复能力、超常体质及一定战斗经验。普通食物只能有限稳定伤势。察觉有人接近并停在门前，他决定杀死住户并以血肉恢复，选择节省体力的背后伏击，而非先询问或合作。生命感知不是读心，不能识别主角是否已发现生活异常。

主角18岁、高三、独居、靠补课生活，有专业级生物知识与观察兴趣；遇险冷静行动，不强加恐惧、样本误判或心理缺陷。第一章主要呈现警觉、观察和判断，无须先展示完整知识体系。

敌人的具体受伤原因仍未定；原来历A“剧本重伤归来”仅保留编辑推荐，B同源猎杀、C捕猎受伤仍可后续考虑。不把屋顶逃离自动解释为任何组织正在追捕。第一章不引入异事局或地下组织，两方组织不从全书删除。

## 3. 第一章执行概要

| 阶段 | 具体推进 |
|---|---|
| 日常 | 补课回家，原计划吃饭并完成观察记录；不先写反派或楼顶逃亡 |
| 异常 | 冰箱冷光尚可解释为疏忽；地上包装和陌生污迹使主角判断有人侵入 |
| 伏击 | 主角立即准备退出，敌人发现动作变化而发动；提前反应仅阻止完整锁控，主角仍受撞击 |
| 对抗 | 借餐桌争取距离，敌人直接推桌逼近；主角被逼向厨房，看到爆发后的停顿和旧伤恶化 |
| 反杀 | 敌人选择速决，连续发力后支撑失效；主角抓住窗口，利用已铺垫的厨刀完成致命反击 |
| 代价 | 主角先前受伤带来的异常持续，试图拿手机求援但未成功，随后昏迷 |
| 超凡尾声 | 明确分隔后以短小外部镜头表现自噬清理、红色物质侵入；不讲解机制 |

预先准备＋生理失控仍是胜因；“准备”更新为异常确认后的临场退让、保留空间和避免被控制，不再是有供食时间的复杂布置。具体空间、铺垫和动作以章卡为准。

## 4. 自噬、清理与感染

已定：进化者死后，本源种子自噬回收遗体，并吞噬衣物、随身物品、血迹及其留下的全部相关痕迹，形成红色活性载体，侵入昏迷中的主角，启动初次进化。采用超凡解释，不为不同材质逐项增加科学限制；O7“衣物和血迹必须保留”的要求撤销。

此过程属于本源种子，独立于无限流系统；不是系统代为清理、不是击杀自动领取奖励，也不设载体独立人格。视觉可用身体与衣物一同收束、痕迹淡去，最后只剩红色物质。主角未目睹自噬与侵入。

清理不自动抹除记忆或治愈主角外伤；本轮不新增全城痕迹抹除、远程记录删除或房屋复原规则。章卡避免制造大规模建筑破坏，也不保留与最新要求冲突的进化者物证。

生命感知仍来自死者额外基因片段；感染不等于继承全部战力。载体携带唯一精华、回收是否占主角解析冷却及改造能量来源仍为机制提案；不因超凡清理自动确认。第一章只写进化启动，完成时点与昏迷持续时间在第二章衔接。成功感染起算首轮七天，有效进化完成重置并开始四十八小时进化冷却的规则保留。
