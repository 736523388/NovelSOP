## 1. 当前开篇主链（作者已定）

1. 某个周末，主角补课回家，在租住处楼道里遭遇逃亡进化者。
2. 进化者为寻找藏身处控制主角，随主角进入租住的小屋，最初要求主角提供食物；他从一开始就没准备留下活口。
3. 躲藏期间，进化者身体状态继续恶化，决定把主角当作血肉恢复素材。
4. 主角察觉对方意图，凭借熟悉环境、判断人体异常状态和冷静分析局势，主动先发制人，经过搏斗险胜并杀死对方。
5. 进化者死亡后，残存活性组织感染主角；主角随后吞噬这名进化者。对方含有大量额外基因片段，因此可作为主角的有效进化素材。
6. 异事局后续在附近街道范围搜寻。当地是老旧城区，几乎没有监控，此次没有查到主角头上。
7. 沿用上一轮后续方向：主角察觉身体变化，系统征召突然出现，并在前三章内进入首次剧本。身体变化、吞噬过程和征召的具体交错时点尚未划定。

此次修订将搏斗地点由笼统的楼道明确为进入出租小屋后的室内冲突；“主角接受异事局检查并隐瞒遭遇”不再作为当前版本必经事件。此前版本保存在 revisions/opening-plan-o1.md，后续以本文件为准。

## 2. 逃亡进化者（作者已定）

- 他是具有理性、把自身生命置于一切之上的人，并非疯狂失控的怪物。
- 进入小屋后先索要食物，但从一开始就打算灭口；身体恶化使他进一步决定把主角当作血肉恢复素材。普通食物的即时作用和索食时的具体话术另定。
- 他已有吞噬血肉修复伤势的能力。这是该人物的一项具体能力，不能直接推广为所有感染者初始自带的能力。
- 沿用原设定的重伤、军事训练与强化体质背景；具体身份姓名、阶位、伤势和外在表现待定。
- 主角察觉其杀意并先行反击，体现准确判断与行动力；险胜可来自双方实力差距和外部处境，不安排主角误判样本或失智犯错。

## 3. 两种吞噬的区别（已定衔接）

| 用途 | 机制 | 本场景中的主体 |
|---|---|---|
| 吞噬血肉修复伤势 | 逃亡者既有能力，利用血肉恢复自身；不以获取新基因、完成新进化为前提 | 活着的逃亡者准备对主角使用 |
| 吞噬进化 | 合格新基因信息经过解析—吸收—进化完成，受能量、耗时与冷却规则约束 | 主角感染后对死亡进化者进行 |

普通人类不能提供主角尚未拥有的人类基础代码，但这名进化者含有额外基因片段，故成为合格素材；主角只利用新增有效代码，重复的人类基础部分不参与进化。死者具有血肉修复能力，不意味着主角吞噬后自动继承这项能力或全部战力。

## 4. 顺序及边界

- 必须先击杀，随后死后组织才产生低阶感染作用。交锋中的接触与真正感染成功的时点需分清。
- 感染成功即开始初期7天生存计时。最初感染有身体和意志承受风险，应在场景中予以体现，具体表现未定。
- 作者已确认主角感染后吞噬死者；正式展开时仍遵守解析—吸收—进化完成，解析耗时与其后的24小时冷却、进化耗时与其后的48小时冷却均须保留。
- 接触吸收型的既定方式保留，不默认改写成普通口腔啃食，也不默认一次接触瞬间完成所有步骤。
- 死亡宿主生命精华只有一份的规则保留。本场景尚未确定其形成与吸收的具体外观、本源绑定细节及是否留下物质残余。
- 主角首次核心性状为生命感知，来源已确认是死者的额外基因片段，并在第一个剧本中应用。死者的血肉修复能力不因此自动被主角继承。
- 系统征召与种子能力保持独立；事件前后相接不自动等于感染导致征召。

## 5. 异事局搜寻（作者已定方向）

异事局在附近街区搜寻，旧城区几乎没有监控，未查到主角。当前不安排主角面对面受检或被锁定为疑似感染者。

场景写作建议（未定）：保持搜寻范围与已有线索相称，表现为追踪在街区内失去明确方向，暂未锁定出租楼或主角。具体线索、到达时点及其他住户是否注意到动静，需在场景设计时一起核对。没有监控是已定环境条件，不据此宣告现场不存在其他线索或异事局永远无法查明。

早期感染难以确诊仍是世界规则，但本场景不必靠检查结果解释主角暂未暴露。主角此前担心被当研究对象的心理可以保留为未来动机，当前没有因正式讯问而撒谎的必经情节。

## 8. 反杀场景建议：重伤下的短暂爆发（暂用草案，待细化）

作者于2026-10-08表示“先这样，后续再继续”。本方案保留为续接用草案，具体动作与道具未定稿，不据此把全部细节升级为已定。优先利用现有的重伤、体能透支、室内环境与主角的观察能力，不新增主角开战前的超凡能力。

### 场景成立的前提

- 对方完好时的强化体质与当前可持续战斗能力分开：当前仍有一次压倒普通人的短暂爆发，但维持不了连续高强度搏斗。追捕造成的伤势已有实质影响，不能只剩衣服上的血迹。
- 主角观察到对方移动后恢复缓慢、姿态依赖支撑等连续线索，由此判断其强势难以维持。具体外观线索在正文里应先出现，再写主角采取行动。
- 进化者仍警惕、会反击；主角清楚等待对方恢复会更加不利，主动抓住眼前窗口。
- 屋内生活用具与拥挤布局在进门时自然交代；关键道具须提前出现。具体平面图、工具和动作尚未确定，不写成临时出现的便利武器。

### 推荐的五段因果

1. **控制与观察**：逃亡者索要食物，保持威胁和控制。主角利用熟悉的生活流程观察，逐渐察觉对方正在把自己当成恢复素材。
2. **主角先手**：主角主动打破僵持。可用近处小桌被掀翻、双方争夺厨房用具等已有环境元素起势；这些具体动作只是候选，首次反击不直接结束战斗。
3. **对方反压**：军事训练和残存力量发挥作用，对方挡住攻势并逼近主角；家具在短促冲突中倾倒、双方受伤，主角一度被压制。险境来自对方真实实力，不安排主角惊慌犯错。
4. **既有重伤兑现**：这一轮爆发使对方失去继续维持压制的能力，原有伤势与消耗表现为明显衰弱。主角此前的判断在此得到验证，窗口由交锋中的消耗与伤势推进形成，不靠对方突然分神。
5. **结束威胁**：对方仍试图吞噬主角，主角抓住压制松动的机会，以先前已进入争夺的武器完成最后反击，致使对方死亡。具体动作待场景布置确定，不依赖精确人体解剖致死技巧，也不让主角徒手压倒完好强化者。

### 读者应当感受到的胜因

主角判断正确、先行动、熟悉环境；对方的重伤与无法持续作战使这些优势得以兑现。即使主角选择正确，也可能因身体实力差距受伤，形成险胜。战斗宜短促，避免重伤者还能长时间全力追打，削弱胜因。

死亡后再出现感染性组织的变化，衔接已定感染与吞噬主链。主角普通外伤如何处理不得自动套用“诅咒损伤随进化完全修复”的规则。

## 9. 小屋场景细化（O4 新提案，未确认）

推荐采用“索食提供活动机会，观察决定出手，旧伤限制反压”的安排，将第8节暂用结构落实为以下场景链。

空间暂拟：入口旁为简易料理区，小桌位于料理区与床之间，过道狭窄。逃亡者占据能看住门和主角的位置，借桌沿支撑身体；主角在其视线内取食物。桌椅、餐具在索食时自然出现，不能交锋到一半才补出救命道具。对方防弹衣沿用既定装备，不临时脱除，也不安排普通餐厨工具轻易击穿防护；具体终结动作待章卡确定。

| 节拍 | 可见行动与信息 | 选择及因果 |
|---|---|---|
| 索食 | 对方要求食物，制止主角靠近门或拿取通讯工具；主角照办 | 对方需要补给，也保持控制；主角取得有限活动空间，不等于对方失去警惕 |
| 观察 | 对方两次改变姿势后都需停顿，扶桌时间变长；仍能迅速制止主角接近出口 | 连续线索显示爆发力尚在，持续体力不足；主角判断直接逃跑会遭拦截 |
| 杀意显露 | 食物已在手边，对方却停止取食，转而要求主角走近，并开始伸手控制他 | 主角无需知道吞噬疗伤的术语，也能判断服从不会换来安全 |
| 主动先手 | 主角借两人之间原有的小桌形成阻隔，争取使用料理区里已出现的物件 | 目标是打破控制；不把计划押在预测旧伤何秒发作上 |
| 反压与代价 | 对方突破阻隔，靠训练和力量将主角压回狭窄处；主角受伤并继续抵抗 | 对手实力得到兑现，爆发消耗与旧伤使其压制逐渐松动，呼应先前观察 |
| 最后反击 | 主角抓住实际出现的松动继续反击，最终使对方死亡 | 由主动抵抗与对方重伤共同形成胜因，不靠外人救场或敌人突然失神 |

交锋宜短促。主角判断大势正确、随局势变化行动即可，无须预知全部过程。逃亡者因为继续衰弱而急于取得血肉，双方都有“不能再等”的理由。

感染衔接候选：死亡时主角尚未完全脱离近距离纠缠，死后活性组织发生变化并接触主角，造成感染。无需安排主角脱险后出于好奇主动触摸未知组织。变化速度、感染所需接触时长及视觉表现仍待确定。

感染后先写身体异常与主角承受、观察的过程，再进入解析和吸收。主角可观察到死者明显异于普通人的组织特征，据此选中合格素材；不让他无来源地知道本源历史或全部规则。剩余生存时间的本能认知按 INFECT-08 使用。

异事局未查到主角的结果保留；正文还须交代冲突动静是否被听见、搜寻人员最后掌握的线索到哪里。不追加“所有邻居恰好不在”，也不靠吞噬后现场自动无痕解释未被发现。

## 10. 首次进化与征召的衔接（O4 新提案，未确认）

| 方案 | 顺序与回报 | 需要承担的情节条件 |
|---|---|---|
| A 小屋完成，入场应用（推荐） | 感染 → 解析死者 → 吸收并完成生命感知进化 → 突然征召 → 第三章入剧本，随后让能力改变行动选择 | 小屋须提供足够过程时间、能量与休息条件；第二章通过少量身体变化与时间转场表现等待 |
| B 小屋吸收，剧本内完成 | 感染 → 解析并吸收 → 进化中被征召 → 剧本内完成并应用 | 先明确改造期间的行动能力、投送是否影响进化、落地后的生存安排；若需休眠，不能直接让主角正常战斗 |

推荐A：首次进化有独立的完成回报，进入陌生环境后即可展示用途；不必同时解决进化中投送、行动能力与休眠场所三个问题。第二章可以通过转场覆盖当晚至次日，不必把两章事件都压在几十分钟里。这只是叙事窗口建议，不是统一处理时长，也不表示系统会等待主角准备好。

### A 的相对时间线

| 节点 | 状态变化 | 计时核对 |
|---|---|---|
| T0：成功感染 | 承受第一波反应，随后具备解析与吞噬能力 | 首轮7天从此刻开始，第一波反应计入期限 |
| T1：开始解析 | 对死者合格组织进行解析 | 消耗实际时间；首次解析起始可用为本方案待确认前提，不凭空追加24小时等待 |
| T2：解析完成 | 得到唯一一份生命精华 | 解析冷却到T2＋24小时，不封锁满足自身条件的进化 |
| T3：吸收并开始进化 | 能量准备满足所需规模后直接吸收，无需依赖尚未获得的系统背包 | 保留过程耗时；T3不要求晚于T2＋24小时；首次进化起始可用同样待确认 |
| T4：进化完成 | 获得生命感知，修复本轮诅咒损伤 | 须早于T0＋7天；新期限为T4＋7天，进化冷却到T4＋48小时；普通外伤不自动痊愈 |
| T5：征召并进入剧本 | 带着已完成的身体变化进入新环境 | 建议首次真身进入，仍待确认；征召不清空生存计时与冷却，不解释为感染触发 |

具体解析和进化耗时随本次素材复杂度、改造规模统一确定，不在本轮追加全局数值。若采用A，第6节第二章安排补入首次进化完成；生命感知的首次关键应用仍放在第一个剧本中。第三章内进入剧本的要求保持。
