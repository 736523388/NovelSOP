## 2. 主要问题与处理

| 问题 | 旧稿表现 | 本轮处理 |
|---|---|---|
| 段落节奏过于机械 | 大量孤立动作句、判断句，各占一段 | 将连续动作、观察和即时反应写在同一段；保留冲突转折及对话的短段 |
| 作者替人物解释 | “这是变化”“还够做很多事”、排险后的总结 | 通过移动盒子、落笔记录、拿物件、查看路线呈现，不在场景后补结论 |
| 反复申明限制 | 多次解释不冒险、不乱碰、不全知 | 以实际停手、退回、换路表现选择；删去重复辩解 |
| 配角像共同朗读流程 | 台词概括情况、复述任务、交代完整背景 | 祁岚回答上次如何离开，贺程先试手机并看设备，许棠注意途中眩晕；对话贴合现场 |
| 句子空泛或搭配不当 | 视线里有变化、疼痛亮了一瞬、衣服陷进凹陷身体 | 改为看见拿刀动作后扑来、摔倒眼前发黑、衣服随身体一同凹陷等可见动作 |
| 手持物与动作冲突 | 伤臂受限时又用右手照明、扶墙、抬罩；放下罩子顺序不清 | 维护道先收手机借同伴灯光，停下再取；抬罩前把手机放到凳上，排险后拿回；许棠先放罩再退开 |
| 编辑引入的重复及错误 | 记录纸两次装包、左臂两次同样安放、把系统倒计时写成手机屏幕数字 | 回读时合并动作，明确数字位于视野；未把系统文字变成手机可拍内容 |
| 结尾刻意总结 | “去北岸的路上……而撤离任务……”替读者解释矛盾 | 保留供电会带动水路的对话，以灰丝仍活跃及地图上的连接收尾 |

## 3. 保留的事实与边界

- 秦川仍为普通状态反杀重伤进化者，受伤昏迷后才感染；自噬清除死者及全部相关痕迹，不修复家具位置或主角外伤。
- 生命感知只给近处活体线索；螳螂用于验证，不产生无效解析；灰膜判断依靠现场可见证据。
- 生存周期一个月，常规进化完成后七天冷却，首次感染进化不触发冷却；解析仍24小时。前三章只写生命感知，没有第二次进化。
- 原初之饥是已定正式名称，但前三章仍未向秦川揭名；未采用聊天中的其他命名候选。
- 60秒征召、72小时任务、第60—72小时撤离窗口保持；内部时间线仍以T4为准。
- 第三章结束时本室支路隔离完成，污染检修杆留在墙根，灰膜未死；主角手机取回，水、包与纸笔未丢失。
- 祁岚提及前次有人未归及杆上灰丝伸展是本轮局部叙事细节，仍属试写，不据此新增高阶世界规则或配角正式背景。
