# 小说世界观完整设定手册 V2.0

> 架空都市 × 无限流 × 生物进化。标记：**已定**＝用户确认；**建议**＝可修改；**待定**＝尚未决定。

## 一、核心设定

**已定**：主世界是超凡力量长期隐秘共存的架空都市。主角意外卷入秘密追捕行动，导致一名重伤强化进化者死亡，沾染死者释放的活性组织，被迫获得独立于无限流系统的进化能力。黄金三章内进入首次剧本。

**已定**：所有进化能力来自一个已死亡高等生命的碎片。进化者通过解析、吞噬生命演化；不同碎片因果律互相吸引，可能相互吞噬，最终指向生命升格。小说以爽感与内部自洽为优先，不强求现实生物学合理性。

## 三、主世界与异事局

**已定**：采用**隐秘共存型**。超凡存在已久，官方和大型组织维持秘密秩序；社会有传闻和异常视频，却无公认可靠证据。主角开篇完全不知道超凡力量与无限流。

**已定**：官方机构名为**异常事务管理局**，简称**异事局**。它对进化者**部分知情**：知道吞噬成长、死亡释放感染性组织及部分感染抵抗案例；不知道原初生命、碎片同源、因果吸引和生命升格。

**建议**：异事局承担异常调查、特别行动、剧本事务、技术研究，部门名称尚未定案；不是天然反派。其他势力包括合法超凡企业、财团、独立参与者、地下交易和实验组织。

## 四、原初生命与进化种子

**已定**：所有进化种子源自**已死亡的高等生命**，暂称“原初生命”。本源碎片本质是**非物质存在信息**，但可依附物质载体；主角获得时载体是一团**活性组织**。最终目标是**生命升格**。

**已定**：宿主不限人类，其他动物及植物等生命也可能获得碎片。不同物种可以走不同进化路线，不必都变成人形。

### 死亡、感染、转移

1. **已定**：原宿主存活时，本源不能完整转移。
2. **已定**：宿主死亡后，本源解除绑定，活性组织可感染新生命。
3. **已定**：击杀不自动继承，没有最后一击或因果归属判定；沾染并被感染才可能成为新宿主。
4. **已定**：强大超凡者可能抵抗、隔离或清除感染。
5. **已定**：感染不意味着立刻继承原宿主全部战力。
6. **建议**：感染有潜伏/融合阶段；传播细节、感染失败率和离体存续时间待定。

### 因果吸引与同类吞噬

**已定**：同源碎片存在**因果律吸引**，推动宿主命运交汇、相互竞争或吞噬。**因果吸引与感染转移相互独立**。

**建议**：因果律通过自然事件提高相遇概率，不强制控制思想或决定胜负。植物宿主也能经环境、运输等方式与其他碎片相遇。具体强度和屏蔽规则待定。

**已定**：吞噬普通生命获得性状；进化者死亡后，其本源可被其他宿主感染、融合。**建议**：融合碎片增加演化潜力，但不必复制死者全部能力。

## 五、生命进化机制

**已定**：进化依靠**解析和吞噬其他生物**，能力独立于剧本系统，不自带任务面板、技能树或属性点。

**建议**：四步流程为**解析 → 吞噬 → 同化 → 进化**。解析识别结构，吞噬获得素材，同化整合性状，进化真实改变身体。主角的专业生物学知识有明显优势。

**已定**：选择**分阶段进化**：初期被动，后期逐步主动。

| 阶段（建议名称） | 控制程度 |
|---|---|
| I 本能期 | 自动适应，宿主主要选择吞噬对象 |
| II 干预期 | 可强化或抑制某些演化方向 |
| III 定向期 | 主动组合器官、组织和多种生命性状 |
| IV 自主期 | 高度自由设计复合生命结构，走向升格 |

**建议**：成长路线为复制特征、优化特征、创造复合特征。能量、时间、兼容性、失控可作适度代价，但不必过度限制爽感。不同物种宿主路线不同；进化控制阶段不等于战力阶位。

**待定**：具体吞噬形式、效率、进化速度、失败后果、特征数量限制。

## 六、无限流剧本系统

**已定**：系统负责征召、投送、任务、结算、奖励和权限；不能直接管理、升级或剥夺原初本源。剧本类型选择**多类型混合**：生存、探索、规则悬疑、恐怖、战争、文明、历史、都市等。

**已认可**：首次随机强制征召，后续可周期参与、主动申请、特殊邀请；周期具体长度待定。

**已认可**：剧本危险等级为 **F、E、D、C、B、A、S**，综合战斗、环境与规则难度。任务分**主线、可选、隐藏**；结算评价也可用F—S，但独立于剧本危险等级。非战斗任务同样可以获得高评价。

**已认可**：奖励体系为**积分 + 实物 + 系统权限**。积分兑换资源；实物含强化剂、技能、装备、道具、知识；权限含交易、组队、剧本申请、携带额度。具体数值待定。

### 剧本世界与时间

**已定**：真实世界与系统创造的模拟剧本**混合存在**。真实世界有独立文明与历史，剧本结束后继续存在；模拟世界可重置、封存或销毁。**建议**：还可有真实世界叠加临时规则的混合干涉剧本。

**已认可**：时间流速可变，例如1:1、10:1、100:1（仅示例）；生理时间真实流逝。正式剧本死亡原则上真实死亡，明确的保护型训练剧本可例外；任务失败不一定死亡。

**已认可**：物品携带受额度与结算规则约束，**已经完成的身体进化不算携带物品**，不会在返回时被系统剥夺。

## 七、进入方式与本源意识映射

**已定**：以**真身进入为主**，特殊剧本可用**意识投送或身份载体**。身份替代可以是真身伪装，也可结合意识投送。

**已定**：意识投送选择**有限投射**：本源始终绑定真实生命本体，可通过意识提供部分生命解析能力，**不能直接吞噬、同化或改造临时载体**。研究知识和记忆可带回，但知识不等于已完成吞噬，真正进化仍需本体取得素材。

| 规则 | 真身进入 | 意识投送 |
|---|---|---|
| 身体 | 本体进入 | 本体留在托管空间，意识使用载体 |
| 生理进化 | 保留 | 临时载体不直接继承 |
| 本源解析 | 正常 | 有限映射 |
| 吞噬改造 | 正常 | 不能直接使用 |
| 死亡 | 本体死亡即真实死亡 | 载体死亡可能导致本体死亡，保护型例外 |
| 本源释放 | 本体死亡后 | 只有真正宿主死亡才释放，不在载体复制 |

**建议**：系统可限制进入条件、载体、装备和环境，但不能直接抹除本源。模拟世界重置后无主本源的去向待定。

## 八、属性与超凡阶位

**已定**：选择**属性 + 超凡阶位混合体系**。系统评价当前综合实力，不代表成长上限。

**建议**：六维属性：力量STR、敏捷AGI、体质CON、感知PER、精神SPI、能量ENG。普通成年人平均约10点（仅内部参考），属性非线性；不设智力属性，以免机械化主角知识。

**建议**：九阶：一阶初入、二阶低阶、三阶成熟、四阶中阶、五阶高阶、六阶顶级、七阶传奇、八阶神话、九阶已知极限。

**已定（最新选择C）**：**综合评级 + 部分质变**。阶位主要由属性、技能、装备、能力稳定性和实际表现综合评估；不同体系不必按统一仪式突破，但较高阶位通常伴随能力或生命层次的实质质变。具体质变节点待定。

**已认可**：普通参与者可通过强化、技能、装备或复合路线成长；进化者也可获得系统奖励。进化者优势在成长自由度和理论上限，**不等于同阶必胜**。

## 九、第一章冲突背景与善后

**已定**：第一章采用**秘密追捕行动失控**。地下组织利用剧本资源开展强化实验，一名实验对象兼为原初本源宿主，逃亡后被地下组织追捕，异事局介入，多方交火。

**已定**：逃亡者受过军事训练，可能使用强化剂，体质至少约普通人两倍，穿戴防弹衣等军事装备；重伤后丢失枪械。主角无超凡能力，但冷静主动地解决威胁，导致进化者死亡，随后因沾染活性组织被迫感染。

**建议事件链**：放学后观察生物 → 附近混战 → 重伤逃亡者与主角遭遇 → 主角主动促成其死亡 → 活性组织感染 → 异事局封锁调查。具体战斗场景尚未敲定，不必让主角恐惧、慌乱或犯错。

**已定**：异事局部分了解感染风险，因此调查应专业。**建议**：感染潜伏期、地下组织回收部分组织等使调查出现多个方向；主角作为幸存者接受调查，但暂未被证实感染。后续剧本参与者身份可以成为外界解释其超凡能力的表面来源。

| 章节 | 推荐内容 |
|---|---|
| 第1章 | 秘密追捕失控、主角导致进化者死亡、活性组织感染 |
| 第2章 | 异事局调查、主角研究身体异常、收到剧本征召 |
| 第3章 | 真身进入首次剧本、系统发布任务、发现可解析异种生命 |

**建议**：第一卷暂名《初始演化》，约60—80章：感染与征召 → 首次剧本 → 进化突破 → 重返都市 → 首次深入接触其他进化者。篇幅、卷末阶位均可调整。

**建议首次剧本**：《第七生态实验区》，真实世界、真身进入、生存探索；废弃生命实验设施生态失控，任务可为72小时内生存并撤离。甲壳异种、捕食植物、再生两栖生命可提供不同素材。**剧本名称、任务、怪物与第一次进化方向尚未正式确定**。

## 十一、双体系交互原则

1. **已定**：系统可以给强化剂、技能、装备、知识，但不能升级原初本源。
2. **已定**：吞噬带来的身体进化永久属于主角，不受物品携带规则剥夺。
3. **已定**：意识投送仅有限解析，不能直接吞噬和改造载体。
4. **建议**：主角可研究系统强化剂带来的生物变化，但非生命类时空等规则能力不默认可复制。
5. **建议**：系统可以正常给主角低阶实力评价，而不知道其无限演化潜力。
6. **待定**：系统是否知晓原初生命真正存在、二者历史是否有关。

## 十二、尚待确定的问题（按优先级）

### 优先级P0：动笔前

- 第一章具体冲突与高潮：主角如何主动造成强化进化者死亡；感染场景怎样表现。
- 进化吞噬的具体形式，以及首次解析、吞噬、进化的视觉表现。
- 第一次剧本的最终主题、目标、关键角色和第一个进化成果。

### 优先级P1：第一卷写作中

- 主角姓名、架空城市名称、学校与孤儿院日常人物。
- 异事局组织架构、调查负责人、地下组织名称与目的。
- 属性数值标尺、九阶质变节点、剧本积分经济。
- 本源融合后的收益、进化代价和进化速度。

### 优先级P2：中后期伏笔

- 原初生命死亡原因、碎片散落机制与升格终局。
- 因果吸引的强度、跨世界作用与规避方式。
- 系统真正来源与目的；模拟世界的意识、死亡和重置本质。
- 被退养的真正原因及其揭示时机。

---

**创作红线**：不要把进化写成系统技能；不要把击杀写成自动掉落归属；不要让活宿主完整转移本源；不要默认所有进化者都是人类；不要强迫主角恐惧犯错；不要把未确认建议当成已定世界规则。
