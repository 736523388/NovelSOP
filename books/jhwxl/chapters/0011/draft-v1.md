# 第十一章 空白的交接栏

维修站的墙上贴着一张旧合照。

秦川先前以为窗边那只空鞋属于照片里某个人，直到罗绍平收拾行李，将另一只鞋从床底勾出来，才知道只是鞋底开胶，拿去晾着了。

他帮老人把折叠筏抬到门边，没有问那些还留在墙上的人去了哪里。

罗绍平自己开了口。

“撤了两批，后来再没联系上。那时候西边还能走车。”

“你怎么没走？”

“第一次少人，要等。第二次水上来了。”他拽住筏边打结的带子，“再后来，我也不想等了。”

结太紧，秦川用右手慢慢解。许棠处理过他的擦伤，掌心贴着一小块敷料，动作比平时笨些。

祁岚在外间清点四人的东西。她把不再需要的固定盒和损坏的箱盖都留下，只留能带走的水、食物、图纸、工具和绳具。贺程尝试修复手柄的接头，失败后干脆换了一段备用线。

那根接头好转，屋里立即响起北岸传来的单调敲击。

罗绍平朝那个方向看了一眼，将柜门打开。

“要拿就把这一册也拿去。前一拨人碰了什么，上面都有。别再照他们做一遍。”

记录册比先前那本厚，里面夹着工单和手写便条，纸边被湿气泡得卷曲。秦川翻到事故前几天，看到许多并不陌生的词：隔离、供能、取样、复核。后面的签名越来越少，最后几页只有罗绍平一个人的笔迹。

最初的灰膜被称作复合净水层，用来吸收水里难处理的残余物。投放记录很谨慎，每一池都有留样，也有定期清除的要求。它不是一开始就会爬出水槽追逐动静，最早几页的照片里，只有固定在滤板上的薄薄一层。

后来改变的是食物和水路。

一批受损实验动物被冲进了回收池。记录显示，他们及时关过闸，也切掉过几个支路，但另一套仍在运行的维护程序把池里的东西重新送回主循环。

有人写下“先保住供氧”，另一行则是“北岸尚有待转运人员”。

秦川把两张工单的时间对在一起。

关闭水路会让某些还没撤走的动物和人失去支撑，维持循环又会把已经改变的东西送出去。后面的涂改很多，有一处纸被笔尖戳穿，穿孔旁只剩半个“停”字。

他没有找到一个按下错误按钮就能解释全部事故的人。

罗绍平在窗边说：“我那天只知道还有人没到。开了两分钟，后来再关，已经晚了。”

秦川抬起头。

老人没看他，正用布擦筏底的一处旧补丁。那块地方已经擦过几遍，再擦也不会变成新的。

“你们要走就走。别替我把这件事说得好听。”

秦川将记录册合上了一半，手指夹住关于机械联锁的那页。

“现在这根杆，能让那条命令失效？”

罗绍平放下布，走过来看了看他指的位置。

“单独脱开，就不会再跟着复电一起动。闸门停在现位。你们不要全关，全关会把压力顶到西渠。”

秦川点头，用笔将“隔离联动”和“关闭全部水路”分开写。他原先画在纸上的转动方向有一处需要改，罗绍平顺手改正，又将实际手柄位置画了出来。

这次老人没有说他年轻，也没有问他为什么知道那么多虫子的事。

翻到记录最后，几张不同纸质的便条掉下来。

其中一页不是维修人员写的。字很小，日期下面只有几个身体状态的词，页边画着一只手，指节外侧是一排明显不属于普通人的凸起。

秦川的手停住。

上面有一行字被划掉，又重新写在旁边。

“不是每天少一天的病。完成以后重新算。”

另一处写着“同类残留，不要徒手处理”，再下面只有“二十四”和“七日”两个独立数字，中间一段被水渍抹开，无法辨认指的是什么。

秦川没有将那些数字立刻对到自己身上。他目前只有一次完整经历，尚不知道那两种阻滞分别持续多久。但关于期限的那句话，恰好是他今天以前才得出的结论。

他把便条翻过来。背面印着实验区餐厅的旧菜单，显然只是有人临时拿来记事的废纸。

“谁写的？”

罗绍平扫了一眼。“前一拨里的一个。老往库里找吃的，最后也没回来拿包。”

“照片上哪个？”

“拍照的时候不在。那人不爱站在人堆里。”

“他去了哪里？”

“不知道。有人说往南去了。”

南边是秦川他们进入的方向，却不能由此证明两次征召投送在同一处，更不能证明纸的主人就是闯进出租屋的男人。秦川只在记录纸上抄下原句，连涂改的位置都留着，然后用手机拍了便条的正反面。

祁岚从门口走来，看见他正在画那只手。

“有用？”

“可能跟我身上的变化有关。”

“认识那个人？”

“不认识。”

祁岚看了一眼纸上画出的凸起，没有再追问。她将自己的手套搁到他旁边，让他试试戴着能不能握住工具。秦川戴上右手那只，虎口稍宽，活动起来却比直接磨着掌心舒服。

“过桥的时候用完再还。”她说。

秦川应了，将那张便条单独夹进自己的记录，不拿走整册工单。罗绍平说旧纸随他带，重要的线路记录要留到他们出发，最后再给他们需要的几页。

傍晚，西侧最后一道闸开始下降。

这一次他们就在维修站里，能听见齿轮转动时一声声吃力的闷响。罗绍平撑着杆站在操作窗前，贺程按照他的指示看外面的标尺，报了几次读数。秦川和祁岚把浮筏推到门边，防止一会儿水位变动时卡在窄门里。

水流从窗外缓缓改了方向。

水面上的灰层被拉出一条长缝，下面露出真正的黑水。秦川感到近处大片细碎的活性正相互挤压，有些随水远去，有些贴住墙根，仍留在原处。

他不再试着分清每一团。

需要记住的是哪一面墙有活物，哪一段绳不能垂到水里。更多的东西，以他现在的能力没有办法从那片混乱里辨出来。

天色暗下去以前，西渠露出了半截黄色桩头。

罗绍平看了很久，终于转身去拿床上的包。

包很轻，里面只有食物、水、证件和几张照片。他把合照从墙上揭下来，卷成细筒，塞进水瓶旁边。

“明早我走。你们今晚去南侧高台，别和我从一条门出去。”

他从记录册上撕下完整的线路页，在最下面写上日期，又签了名字。

秦川看到签名旁边有一栏“接收人”，此前始终空着。

贺程接过笔，写下自己的名字。祁岚凑过去，在后面添了一个名字，随后把笔递给许棠。轮到秦川时，纸张在他右手下轻轻动了一下。

四个名字写完，罗绍平把这一页折起，交给了他们。
