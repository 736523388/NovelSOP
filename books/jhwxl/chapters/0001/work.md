## 2. 章卡

- 视角、时间、地点：主体第三人称紧贴主角；某日补课结束后的傍晚或夜间；六层步梯楼顶层出租屋。死亡后用明确分隔的短小外部镜头。无敌人内心切换，无楼顶逃亡开场。
- 日常目标：回家吃饭；异常出现后改为安全退出；退出失败后改为避免被控制并结束威胁。
- 敌人目标：先在空屋觅食恢复；感知住户归来后决定伏击，取得血肉恢复自身并消除暴露风险。没有必要先控制住户供食。
- 阻力：敌人有超常力量、生命感知与一定战斗经验；主角不知超凡存在，也没有时间拨号或搭建机关。敌人重伤，但仍能进行少量短促爆发。
- 关键选择：发现异常先退出，不深入搜查；遭袭后利用家具间隔，不正面拼力；发现爆发后停顿，改变行动以迫使对方再次移动；把握失衡窗口主动反击。
- 结果与代价：主角杀死进化者，自己因交锋受伤而昏迷；本源吞噬遗体、衣物和全部相关痕迹，化为红色物质侵入并启动初次进化。主角尚不知道感染。
- 读者回报：普通状态下的主角凭警觉、观察和行动获胜；胜利后出现新的未知变化。
- 推进伏笔：本章计划标记K01“食物与异常恢复”、K02“爆发后停顿”、K03“尸身及痕迹消失”、K04“红色物质侵入”。这些是章卡计划ID，未写入正史账本。
- 信息边界：主角只确认入侵、超常力量和严重伤势；不知生命感知、吞噬动机、种子、精华或系统。读者到章末额外看见清理和侵入，但不知道其术语及全套机制。
- 章末期待：他获胜了，但侵入身体的东西是什么？醒来会发生什么？
- 篇幅与文风：初始预算3200—3800字、分场约3400字；实际试写采用约2000—2300非空字符，保留原分场预算作设计参考；动作清楚，判断短促，少解释术语。此为本章执行建议，不冒充作者已认可的全书风格样本。主角姓名确定为秦川。

### 2.1 空间与物件

以下是创作布局，不按建筑比例；本次由Agent作为常规场景设计给出，作者可整体调整。

~~~text
                楼顶／室外
┌────────阳台──────────┐
│ 床、观察架          厨房台面 │
│                   刀架、冰箱│
│         餐桌                │
│         椅子        厨房入口│
│  入口短过道                 │
│  壁柜形成的凹位             │
└──房门／公共楼梯───────────┘
~~~

- 从房门进入短过道，经过壁柜才能看全主室；厨房半开放，冰箱光可从门口斜向看见。凹位在主角通过后落到其后侧，能够容纳伏击者。
- 主角刚入主室、尚未走到餐桌中央位置，就看见地上的包装和陌生污迹。发现危险到退身仅几拍，不在屋里慢慢勘查。
- 路线：房门→短过道→主室边缘；受袭后被逼到餐桌内侧→借桌面形成间隔→桌子被推移，主角退向厨房台面。没有绕屋跑圈、跳阳台或瞬移穿家具。
- 敌人在第一下扑出后占据通往房门的一侧；出口物理上存在，但已无法安全抵达，不靠临时反锁制造困局。
- 厨刀本来位于厨房台面刀架。第一次看清厨房时带到它的位置；到反击才取用，不让主角进门即为战斗拿刀。椅子只提供短暂阻隔，桌椅不具有困住超凡者的强度。
- 手机在书包侧袋；主角正常放包后发现第二个异常。书包留在近入口的椅旁，袭击后被敌人与餐桌隔开。胜后试图回去求援，使其最后行动有明确目标。
- 不安排家具粉碎或墙体坍塌，以免动作强度失控。超凡清理仍按最新“全部痕迹吞噬”执行，不偷偷保留物证；没有必要用修复建筑来制造新的能力展示。

### 2.2 幕后时序（作者与写作输入，不在开篇逐项讲出）

1. 重伤进化者在连片楼顶逃离，选中顶层无人房间，经阳台进入，翻找厨房与冰箱；实际受伤原因、逃离对象均暂不揭示。
2. 食物暂时稳定状态，却不足以恢复。生命感知结合逐层接近、停在门前的脚步让他知道住户回来；他放弃收拾现场，进入凹位准备伏击。感知不是读心，不知道主角会注意哪些生活细节。
3. 主角回家后，敌人等待一个节省体力的背后控制机会；发现主角转向门口便提前发动。等待是为提高成功率，不是故意给主角侦查时间。
4. 在正文主体中不倒叙上述过程。主角只见其结果；“楼顶进入”和“生命感知”可作为后文解释，不强行让主角本章知道。
5. 本章真实时序是击杀→主角失去意识→自噬清理→红色载体侵入→初次进化启动。进化完成不在本章冒充已发生。

### 2.3 分场行动

| 场景／预算 | 行动、阻力与选择 | 信息变化及下场原因 |
|---|---|---|
| S1 回家／250字 | 补课结束，主角确认收到报酬，想着冰箱里留下的晚饭；走上六层，开门。日常只取一两处细节，不介绍完整身世。 | 建立独立生活、观察兴趣和原本平常的一晚；不预告“命运改变”。 |
| S2 冰箱没关／350字 | 门口看见厨房冷光，只觉得自己可能没扣好门；正常入屋放下书包。随后看见不该在地上的食品包装和陌生污迹，意识到不是单一生活疏忽，立即准备退回。刀架在厨房环境描写中自然露出。 | 第一个线索允许普通解释，第二个才触发危险判断；没有明知有人还往深处走。 |
| S3 伏击未成／450字 | 身后突然有人逼近。主角因正在退身而没有把后背完全交出去，避开完整锁控，但没能躲过接触，被冲撞到主室。敌人立刻压近，主角退到餐桌另一侧；敌人此时位于出口侧。 | 主角不是反应速度超过超凡者；提前动作只避免一击结束。超常力量第一次成为直接事实。 |
| S4 第一轮反压／550字 | 主角以桌子争取间隔。敌人不绕桌追逐，直接推动桌子压缩空间，把主角逼向厨房一侧。主角肩背受撞，额侧在失衡中磕碰，耳鸣和动作不稳开始出现。敌人完成爆发后却短暂撑住桌面，衣料上的旧血迹继续扩大。 | 主角与敌人的代价同时出现。主角只能得出“力量很强，但无法连续维持”的初步判断，不能诊断超凡器官。 |
| S5 观察变成行动／500字 | 敌人短暂停顿仍守住出口，主角没有安全逃跑机会。他用身边椅子维持最后一小段距离，向厨房台面退。敌人调整位置再次接近；这次停顿更明显，原先支撑身体的一侧也在失稳。主角看见刀架，但不贸然离开遮挡去拿。 | 第二次征兆验证第一次观察；主角开始保留下一步行动余地。敌人持续知道其方位，没有被家具骗过感知。 |
| S6 最后强攻与反杀／700字 | 敌人判断不能拖延，排开椅子，强行冲过最后间隔。主角预留的侧向位置让他没有被正面压住，却仍挨到冲撞，撑在厨房台边。敌人的连续发力在此刻断开，支撑失效，原定后续抓控未能完成。主角抓到已在身旁的厨刀，在对方尚未重新站稳时完成致命反击；用短促结果句写清对方死亡，不展开解剖式细节或重复补刀。 | 胜因是警觉保命、家具换距离、重伤被行动推至临界、主角执行反击。不能写成只等敌人自己死，也不能靠感染提前增强。 |
| S7 求援未成／250字 | 主角没有发表感想，先确认眼前威胁已经结束，沿桌边朝书包和手机移动。先前的耳鸣、视野不稳和动作迟滞继续影响他；手从桌沿滑落，未能取出手机便昏迷。 | 身体代价在胜负已定后兑现。不可写成刚才毫无异常、为了感染突然晕倒；不指定现实医学诊断或把长昏迷等同疲惫。 |
| S8 超凡清理与感染／350字 | 明确分隔后转外部镜头。男人的身体与衣物同时向内收束，随身物、血迹和相关痕迹被吞噬干净；过程以数个画面呈现，不列物证清单、不解释物理。只剩暗红物质，它靠近并没入昏迷中的主角。冰箱冷光照着原先倒着男人的位置，以主角手指轻微蜷动收章。 | K03/K04启动；主角仍不知情。全章停在感染与进化启动，不跳到苏醒，不抢写第二章系统征召。 |

### 2.4 铺垫与回收检查

| 铺垫 | 回收 | 写作边界 |
|---|---|---|
| 冰箱光、地上包装、陌生污迹 | 促使退离；章末入侵者的物证消失 | 第二章不能继续靠死者血迹或衣物查身份 |
| 手机随书包放下 | 袭击后无机会拨号；胜后明确求援目标 | 不写手机被敌人没收，避免恢复旧供食方案 |
| 厨房台面与刀架 | 被逼到台面后才有最后反击工具 | 不凭空出现，不让主角主动冲向刀架暴露自己 |
| 爆发后的撑桌与血迹扩大 | 再次发力后支撑失效 | 不精确预测发作秒数，不新增冷却条 |
| 主角撞伤、耳鸣、动作迟滞 | 胜后求援失败并昏迷 | 不安排已定致命伤，再靠未确认恢复能力救活 |
| 主角原本的观察习惯 | 短促交锋中不断更新判断 | 不讲长篇生物学，不知道敌人完整机制 |
