# wxl 玩家广场与原核交易

版本：G3 · 日期：2026-10-08 · 依据：作者在运输因果提案后确认“我采纳你的建议，现在继续”。

## 1. 本轮采用的规则

| 规则 | 内容 | 对剧情的作用 |
|---|---|---|
| 玩家交易 | 主神体系设玩家广场，玩家可以自由交易物品 | 提供出售战利品、交换组织和比较成长方案的渠道 |
| 准入 | 非玩家不能进入玩家广场 | 知道超凡存在不等于拥有广场资格；非玩家仍有现实交易需求 |
| 原地返回 | 玩家从主世界某处进入广场，离开时回到该处 | 广场不能作为前往主世界任意地点的传送站，现实运输仍有意义 |
| 原核已知价值 | 交易方已知它可作为完整生体样本被吸收，提高身体素质与恢复能力 | 按稀有强化材料估价、押运和争夺 |
| 原核未知价值 | 持续解析和同化外来组织的机制尚未识别 | 不把卖家写成明知完整能力却低价出手；主角融合后逐步发现 |
| 现实交付 | 玩家卖家出售给中间商，中间商再向主世界非玩家买家交货 | 桥上车辆承担现实交付的最后一程，不是跨世界运输 |

广场的存在和交易不等于可以自选剧本；七天同化也不会因交易、进入广场或买到材料重置。

## 2. 支撑当前开局的工作提案

这些是具体编排，不把作者的一次同意扩大为对所有新细节的批准。

- 卖家是带回原核的被征召者。中间商具备玩家资格，可以在广场接收货物；买家是主世界超凡知情者，尚非玩家。
- 样本在广场完成买卖后，随中间商回到原来的主世界位置，再由专业运输方送往买家的接收地点。车辆只是载具，保护来自武装押运与超凡护送。
- 原核被估作高价值强化样本，押运规格与这个已知价值相称。运输消息泄露使抢夺方得以组织截夺；不需要预设卖家、买家、运输方全都愚蠢。
- 广场提供交易渠道，不默认无条件、无误差地揭示每件未知物品的全部隐藏功能。交易凭已识别信息定价。是否有鉴定服务、费用和识别范围后续按需要设计。
- 本次桥上双方的超凡人员暂按尚未被征召的强化者编排；最初玩家卖家与玩家中间商不在现场。由此不必临时杜撰“玩家为什么不进入广场脱身”的禁令。其超凡可来自流入现实的强化材料，和非玩家买家需求相呼应。

## 3. 原核流转链与知情边界

剧本取得 → 玩家带回 → 广场卖给中间商 → 原地返回主世界 → 武装汽车送往非玩家买家 → 江桥截夺 → 抢夺者带内匣坠至桥下 → 主角被迫杀敌并接纳原核。

| 角色 | 确知 | 尚不知 |
|---|---|---|
| 玩家卖家 | 取得来源，完整样本可用于一次身体重构 | 融合后形成持续同化机制 |
| 玩家中间商 | 已识别功能、真实买家、运输委托 | 主角存在及原核后续能力 |
| 买家 | 买的是稀有强化样本，需要现实收货 | 广场内成交经过的全部细节及隐藏功能 |
| 运输方 | 交付路线、封存要求与货物大致级别 | 生体机制全貌；主角在桥下接纳 |
| 抢夺方 | 有价值的目标、部分运输情报 | 完整长线能力；坠桥者最终遭遇 |
| 官方 | 事后证据、交通事件及部分超凡信息 | 原核真正归属与主角身份 |
| 主角 | 现场实物、伤情、标识和接触反应 | 广场与完整交易链；开场不能凭空说出以上真相 |

## 4. 接引区与玩家广场分开

T3 第二章先写约一分钟的主神临时接引区，然后强制投放首剧。这是本轮场景编排，不是自由交易广场，不给任意进入、躲避危险、选本或地点传送权限。接引在 D0 当晚约 20:10—20:11，按同速一分钟计入当前时间线；广场自身细则仍后置。

### 广场怎样进入连载

提案：首剧先完成独立的求生与 S+ 兑现，再让主角在回到现实后接触广场。这样第一幕不需要介绍货币、商铺和摊位，开篇的物流真相可以随调查逐步揭露。

广场改变的是可取得的素材，不取代实际狩猎。主角仍须判断本轮该买哪种组织、如何保存、是否值得用七天窗口；可以出售用不上的战利品。没有为原核额外设置不可交易、等级封锁或诅咒副作用。

尚未锁定：玩家何时获得入口、进入需要什么状态、停留时间如何流逝、交易媒介与费用。它们不影响当前运输因果；待实际广场场景确定时再落地，不能先假设随时进广场就能躲避一切危险。
