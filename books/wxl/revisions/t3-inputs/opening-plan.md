# wxl 开书设计与首段细纲

版本：A7 · 日期：2026-10-08 · 状态：供审阅的完整设计稿，按本轮作者修改重排开局、首剧风险与成长次序。

依据：[项目档案 P15](project.md)、[人物卡 H4](character.md)、[广场与交易 G2](player-square.md)、[第一幕 F2](first-act.md)。本轮按作者要求改为步行开场、全副武装敌人受创后的可信反杀，以及第三章内进入主神空间并正式开始首剧。运输因果继续沿用 G2。

当前开局：18 岁高三学生周日步行去抓独角仙，沿岸小路经过桥下时被桥面争夺波及；先解决受超凡重创、护具破损且被栏架压住但仍射击的武装歹徒，在正常脱身失败后依据有限线索接纳原核，借增强体质与恢复进入水中潜离。撤下首次融合后团灭双方与高桥跳水，三方暂未识别其身份但继续调查。

人物背景、父母永不出场、初始仅体质恢复、七天、首剧合作与真实死亡、攻防优先、女主后置继续沿用。陆砚、临川、澄江为暂名；具体空间、伤势、融合反馈与钟点是 F2 工作编排，没有终稿事实。

## 1. 主角：陆砚（暂名）

完整人物约束见 [人物卡 H4](character.md)。本轮确认广泛动植物兴趣、顶尖动手、较好体质与协调、较专业绘画、独立电路电器维修、喜欢独处和正常日常生活，以及守序善良、自身利益边界和被动附带杀伤无心理负担。

### 作者确定的成长经历

| 年龄 / 阶段 | 事实约束 | 行为影响 |
|---|---|---|
| 童年 | 在孤儿院长大，不知道亲生父母身份 | 身世是生活背景，不设置寻亲目标 |
| 曾被领养后 | 被送回孤儿院；原因可以不写 | 排斥再次被领养，开始有意表现得“不正常” |
| 此后至高中 | 长期维持异常言行以阻止别人领养 | 怪异有主动形成的来由，内在判断仍理性；不作精神疾病诊断 |
| 16 岁、高一 | 在外独自租房，成绩好，开始给人补课赚钱 | 形成独立安排开销、学习与工作的生活，收入来源清楚 |
| 18 岁、高三 | 仍是学生，周日早晨步行去抓独角仙 | 开篇先看见他的日常安排，再被突然截断 |

亲生父母永远不出场；不安排幕后父母、神秘家族认亲、父母遗产或血统解释能力，不把“不知父母”包装为等待回收的身世悬念。送回原因留白，不添加必须揭晓的伤害事件。被退养经历不用于暗示孤儿会天然暴力，杀伐与判断要由当场行动体现。

### 已确认的兴趣与原有能力

他兴趣广泛，喜欢研究昆虫、爬行动物及各类动植物；动手能力顶尖，身体素质较好、四肢协调强，绘画达到较为专业水平，能够独立完成电路和电器维修。这些都是觉醒前已经具备的本领，不由原核下载。

应用提案：生物观察支撑狩猎假设，绘画用于形态记录和讲义，维修推进设备恢复，协调性支持身体升级后的动作掌握。不能为了队友出场把他写成维修外行；韩策的交通设施系统经验、程闻的声学判断可以与他的实操互补。陌生结构、缺件和信息不足仍需处理，不把动手顶尖写成不看设备就知道所有答案。

喜欢独处，独居日常和常人无异：学习、补课、做饭、维护物品、阅读与画图，不用持续表演异常。具体爱好积累经历、补课科目和持有设备为工作细节，尚未指定；不要擅自增加职业维修履历、特殊学历或已经饲养的动物。

16 岁独租是作者事实，学校、孤儿院和生活联络仍存在；独处不等于无社会联系。

### 外在异常与内在理性

异常言行最初有明确目的：让潜在领养者放弃。持续多年后，其中一部分成为自然说话习惯，另一部分仍可主动控制；这个演变是解释提案。他可以安静修好自己的物品、画一页生物观察图，和熟人交流时才偶尔作出离谱联想。补课时遇到学生真不懂，会把解释讲明白，不能每句都抖包袱。

被退养不是每场戏都要回忆的标签。他最在意的是自己的生活安排不要被他人随意决定。这与原有成长动力相接：探索未知与身体可能性，用实力取得行动自主权。

处事原则按 [H4](character.md) 执行：总体守序善良，坚决维护自身利益，不受道德绑架，不为自己的利益主动侵害他人。面对明确致命威胁果断反击。被动对路人造成附带杀伤时没有心理负担，不安排强制内疚、自罚或人格崩溃；客观伤亡和后续调查不会因此消失，也不把这一心理特点改成主动伤害无辜者。

桥下先手杀敌针对近处的明确致命威胁，随后主动融合并离开，不返回桥面扩大杀戮。人物果决通过眼前选择表现，不以杀尽所有参战者或目击者证明性格，也不额外制造路人死亡。

良好体质和协调让他有执行基础，顶尖动手让临场操作可靠；这些不等于自动具有军事或职业格斗经验。好奇与自信造成的盲点仍为缺点提案，不能盖过本轮明确的能力水平；首剧不借此制造利益内斗。

### 叙述与声音

第三人称有限视角见 [V7](voice-sample.md) 与 T2 完整稿。第一幕从步行经过桥下时突然遇险切入；孤儿院与退养史留给后续合适场景，不在入场前整段交代。重要判断先给可见证据，装疯经历不意味着他始终都在计算每一句玩笑。

## 2. 能力的工作边界

| 部分 | A7 执行口径 | 首段兑现与限制 |
|---|---|---|
| 初始融合 | 身体素质与恢复力提升；不含甲壳或其他独立专门器官能力。桥下首次原核融合暂按约一分钟编排；撤下旧十八分钟参数 | D0 08:10 完成，七天起算 |
| 身体素质 | 力量、体力、持续运动能力提高；水下可维持行动的憋气时长随整体体质提升 | 桥下受伤后进入水中潜离，借已有游泳经验、增强体能与憋气时长脱离现场；不是长出鳃、在水中呼吸或无限憋气 |
| 初始防护 | 尚无独立护甲能力，皮肤不能挡刀、不能凭身体强就徒手接怪物利爪 | 避让、掩体、工具和协作承担战前生存；进化补足缺口有明确价值 |
| 恢复力 | 体力与浅表伤恢复更快，具体倍率待场景校准 | 有伤仍须处理；不使死亡逆转，不自动消除全部伤势 |
| 解析 | 接触有效组织约 10—30 分钟，感知可同化功能；可比较多份素材，不占七天窗口 | 不显示整张地图或替主角给出最佳攻略 |
| 吸收同化 | 贴掌接触样本，重构一个主要功能及其配套结构；首个后续样本预计 20 分钟 | 实体样本与稳定环境不可缺；初始融合不额外赠送一次同化 |
| 间隔 | 从每次完成起计七个亲历日，旧能力使用和解析不重置计时 | D0 08:10 完成 → D7 08:10 可开始；D7 08:30 完成 → 下次最早 D14 08:30 开始 |
| 保存与成果 | 实体组织需保持可用，成果归身体并长期保留，日常保持人形 | 不附加排异、疯狂、掉级；未来特殊结构若取得，可按需显现，当前没有甲壳 |

憋气行动延长按架空身体强化处理，具体分钟数暂不锁定。主角仍会耗尽空气，水路的方向与空间要提前交代；起点在岸边，不再安排从高桥跃下，不赋予水中呼吸或无限停留能力。

成长的常规优先级为：**进攻与防护（含恢复）在前，机动与感知在后。** 攻防内部根据眼前缺口排序，不把“攻击永远压过一切”升级成作者未说的绝对规则。本段采用先提高有效攻击、再补组织防护的具体方案；恢复作为已有底子继续发挥作用，后续可深化。

## 3. 原核事件：桥上争夺，桥下得核

完整六场动作、各方知情与前三章任务见 [第一幕 F2](first-act.md)；交易与广场规则见 [G2](player-square.md)。本节为恢复任务摘要。

运输因果：原核由玩家从剧本带回，按“可吸收强化体质和恢复的稀有生体样本”出售，持续同化能力尚未识别。玩家中间商在广场接货，离开后回到原来的主世界位置，再由汽车向非玩家买家完成最后一段实体交付。运输有武装与超凡护送，情报泄露导致截夺；不用禁止原核进入广场来强造运输。

陆砚在沿岸通往林地的小路行经桥下，不在桥面争夺中心。他原本去找独角仙，尚不知道原核存在。桥上抢夺者取得内匣后被押运方攻击打落，连人带匣落到主角附近；陆砚面对直接杀伤威胁先下手杀敌。

主角已受伤，先试正常退路，发现当前身体无法可靠离开。受损封存匣的实体说明和原核接触反应提供有限用途证据，他主动接受融合。体质与恢复提升后重新完成刚才失败的动作，再从岸边进入江中潜离。初始能力收益当场兑现，但不附带护甲或感知。

各方先追的是遗失货物、坠桥抢夺者和泄露情报，不知道桥下有人已经融合。EMP 只解释部分电子记录中断，桥面生还者的视角也不完整；不要求双方团灭，不抹除物证。三方后续调查继续，主角身份暂未锁定。

现实后果：当天采集计划中断，背包、采集用品与记录本留在现场、身体有伤；没有当天补课失约。周一学校与周二强制征召仍按时间表推进，不能因独居就删除所有联系人。

## 4. 首个剧本：《末班换乘》（暂名）

### 风险与共同目标

六名参与者被投入下沉式交通枢纽“鹭江换乘站”。十八名本站人员与乘客困在隔离区，生物运输事故造成货运支线持续失守。地表出口坍塌，维护短道终点已经被落石封死；它只通向站内备用集结区，不是少数人可以提前逃生的出口。全体需要修复货运撤离线。

入场系统明示：**本次为真实生存任务，剧本中死亡，现实世界也会死亡。死亡不会使参与者退出剧本、回到现实醒来。** 这是一条全书生死规则，并非韩策未经证实的猜测。叙述不擅自补写现实尸体出现地点或身份善后机制。

基础任务：在 144 小时内恢复可用路线并离开封锁区，允许提前完成。地方应急记录显示，六天后隔离设施的剩余能源耗尽，货运转接段将失去封闭能力。附加目标为将十八名受困者全部撤出；深化目标为完成污染源永久隔断，阻止它随交通恢复向外蔓延。

**首剧不安排利益分歧。** 不写抢奖励、争领导权、抢样本、抛弃伤员或为是否救人争执；大家从开始就把恢复撤离线作为共同生存目标。可以有测量误差、知识不足与不同技术判断，由证据和分工解决，不扩写成团队内斗。主世界的交易纠纷、未来杀戮任务仍保留，不能把本次调整误解为全书取消对抗。

### 风险怎样落到行动里

- 入场便看到真实伤者、被撞弯的隔断和清晰死亡提示；规则给出认知，随后遭遇给出证据，不靠故意安排无脑新人送死。
- 第一次正面遭遇时，陆砚能搬开障碍、拉开距离，却无法用普通手段迅速终止敌人的扑击。一名同伴受伤，众人靠掩体与配合撤回。撤退是有能力者面对信息不足的合理行动。
- 安全区逐步缩小：分区供电中断、站内连接段被占据、修复后的设施也要守住。危险改变路径和作业时间，不只是墙上一个不会影响情节的倒计时。
- 受伤会带入后续行动，短暂稳定局面不是自动满血。主角恢复较强仍须避开要害；同伴伤势通过分工补偿，临近结算不凭空消失。
- 六人可以全部活着通过。生死风险靠能够追溯的险情、伤势与解决过程成立，不要求每个剧本固定死几个队友。具体谁受何种伤随正文校准，不能为证明危险强制牺牲某人。

### 其他五位参与者

| 暂名 / 基础 | 有效贡献 | 实际风险 |
|---|---|---|
| 韩策 / 有一次经验的电气维修员 | 以交通设施联锁和供电经验与陆砚分工，陆砚独立修复局部电路，双方核验；只说明自己确知的任务经验 | 维修需要暴露在无法长期防守的操作点 |
| 孟骁 / 野外搜救教练 | 转运伤员、规划分组与备用集结路线 | 一人行动受伤会改变搬运与撤退节奏 |
| 方启 / 仓储调度员 | 核对车辆、燃料、运载量和货运记录 | 错误的库存或路线信息会使全队失去时间 |
| 陈渡 / 自由搏击教练 | 观察攻击动作、牵制和保护作业组 | 人类搏击经验无法直接覆盖异界生物结构 |
| 程闻 / 剧场音响师 | 用现有设备辨认活动规律、辅助定位与诱导 | 机械杂声掩盖生物活动，必须用观察交叉验证 |

其他人无需为主角升级专门停工等待。取样安排在夺回必经检修区的行动内；同化时其他组继续维修、警戒、准备转移。临时合作不发展成主角组织，五人均不绑定女主。

## 5. 狩猎与同化顺序：先把伤害打实，再补防护

下列均为虚构生物，功能来自本书超凡规则。

| 候选 | 组织功能提案 | 眼前价值 | 当前安排 |
|---|---|---|---|
| 束肌猎兽 | 高效收束发力的肌束及配套承力结构 | 主角已有力量耐力，但缺少能迅速中止强敌攻击的有效爆发；改善击打、撕扯与工具发力 | 第一目标；D7 同化，用于必经路的正面破障 |
| 韧膜兽 | 皮下韧性纤维层，分散撕裂与穿刺造成的损伤 | 弥补没有护甲的防护空白；保留自然人形皮肤，不显现几丁质甲壳 | 第二优先；首剧 S+ 选其更完整、更优质样本 |
| 肉组织修复类素材 | 深化已有恢复能力 | 延长持续作战能力，改善伤后恢复 | 属第一优先梯队的其他方案；本段已有初始恢复，先补攻击与抗伤 |
| 附着机动、回声感知类素材 | 改善通行或发现目标 | 有长期用途 | 后置，本剧不安排超声感知同化；工具、照明和协作先满足基本需要 |

攻击优先的理由必须在初战中展示：陆砚并非体力耗尽才失败，而是力量已经提高，却仍难在对方连续攻击中快速造成足够有效伤害。又因没有护甲，拖长近身接触就更危险。束肌进化让他更快结束接触；下一窗口再补韧性防护，减少一次失误的伤害。恢复始终有用，但不能替代挡住致命打击。

肌束进化不是一口气吞下猎兽全部能力，不赠送利爪、护甲、超声或独立机动技能。它增强身体输出与承载该输出的配套结构，仍受既有体格和接触条件限制，不能隔空放出冲击波，也不设计使用后强制虚弱、疯狂或掉级。

### 猎物不是靠尚未获得的能力打到

D3 初战取得少量损伤组织，当日解析只足以判断局部功能，不够完成同化。D4—D5 用生物观察知识提出假设，以形态速写和重复观察记录差异，再根据实际证据选定猎物，先恢复隔断、照明与退路。D6 夺回必经检修区时，队友配合使用环境阻隔，将单个目标与群体隔开，陆砚凭已有体能、工具及观察到的结构弱点完成击杀，取得足量有效肌束。先把狩猎行动做成，再谈同化，不用未来能力解开它自己的获取条件。

D6 下午取得有效样本，使用具备保活指示的虚构封存容器保存至 D7 早晨，次日先核验可用再同化；不默认 D3 零碎组织放到 D7 仍然完好。D7 08:10—08:30 完成同化后，通过短时可控发力验证提升，再参与决战。

## 6. 行动链、S+ 与奖励

1. 入场确认真实死亡规则与时限；队伍核对出口后共同选择恢复货运线路。
2. 首次检修遇袭，陆砚的体力优势足以救援和撤离，却缺少可靠攻击与防护；受伤与失去作业区使威胁具体化。
3. 韩策与陆砚分工恢复系统和局部设备，陆砚的独立维修有可见成果，方启查出货运目标和设备位置，孟骁安排伤员与备用集结区；全队用分工争取存活时间。

### 最高奖励提案

本难度内普通完成给基础资源，更高完成给普通素材选择，S 档给精制样本；**S+ 可选一份源级完整活性组织，并附一只只用于该样本的实体封存匣。** 不给选本权、万能空间或冷却清零。

本次选项为更强输出肌束、韧性皮下组织、恢复组织。主角选择“源级韧膜组织”：同化后建立更坚韧的皮下纤维层，提高对撕裂和部分穿刺伤害的抵抗。它是后续获得的防护进化，表皮外观正常，不把已删除的开局甲壳换名送回。初始恢复底子继续工作，未来再安排专项深化。

选择理由：本次已补攻击，再投入同一项会留下明显抗伤短板；高质量防护比同一窗口继续堆输出更适合下轮未知任务。D7 取得奖励和解析机会，D14 08:30 最早启动同化；在当前卷主世界段实际兑现，不能一直压仓库。源级只表示本次奖励目录最高档，不是全多元宇宙终局强度。
