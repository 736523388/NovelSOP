# wxl 第一幕与前三章节奏

版本：F2 · 依据：作者本轮三项修改；当前正文为 T2，未定稿。

## 1. 本轮改动

主角周日步行去抓独角仙，采集盒与记录本在背包里。直接从桥下遇险开篇；租住处为居民楼，不保留出门遇见隔壁店铺卷帘门的场景。取消单车，不用交通工具维修展示手巧。

桥上武装人员配备头盔、防弹衣、长短枪械等装备。坠桥抢夺者先受到超凡攻击，护甲破损、身体重创，坠落时又被栏架压住；长枪卡在上方，仍能使用副枪，向主角开火。反杀依赖前述处境和短暂行动窗口，主角此时尚未觉醒，不靠正常学生正面压过完整武装人员。

动作只服务具体小说场面，不扩写成装备弱点清单或搏杀教程。短刀来自对方坠落时断开的装具，不能无故出现。原核完整，外匣破损；击破对方装备的冲击来自桥上超凡者，不来自原核或主角。

## 3. 仍成立的原核因果

此前玩家带回原核 → 广场卖给中间商 → 中间商回主世界原位置 → 武装护送向非玩家买家现实交付 → 情报泄露遭截夺 → 携匣抢夺者受创坠桥 → 主角反杀并融合。

交易方仅识别体质与恢复价值，未识别持续同化。主角只读到用途铭片，不提前知道广场及交易内幕。现实交付与玩家广场规则见 [G2](player-square.md)。

## 4. 空间、物品与知情

上层为交战桥面，下方沿岸步道被波及；石阶连接狭窄岸台，岸台末端入水，桥影之外有缓坡。先写普通退路因伤势与交火失败，再融合；强化后能爬起，但上方仍不安全，因此选择水路。

主角离开时，尸体、枪械、短刀、空匣、背包、空采集盒和观察本仍在现场；钥匙、机械表和坏手机随身。不再有单车遗留。房东和院里老师知道遇险，不知道原核；三方不能因此自动获知谁完成融合。

EMP 干扰、桥面桥下视角差和各方有限信息共同构成暂时未暴露的原因，不消灭全部证据，不要求桥上双方全死。后续调查仍须承接遗留物。
